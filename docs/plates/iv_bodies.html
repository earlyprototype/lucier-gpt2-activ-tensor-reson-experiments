Honesty

A body is 48 components rendered through a fixed basis, with each component given equal weight so the shape shows all of them rather than only the loudest two.

That equalising is a display choice and it changes apparent distances, so the separation figures above are measured on the raw state vectors instead, not on anything drawn here. An earlier version of this page reported the opposite result because it measured separation in the display's own coordinates.

Bodies that look alike may still differ along the directions not drawn.
